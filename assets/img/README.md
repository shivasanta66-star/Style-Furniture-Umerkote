Shop photographs go here.

`illustrations/` holds temporary drawings, one for each photo slot on the page,
so the site can be tried out before real photos exist. Replace each slot's
`src` in `index.html` with a real photo, then delete `illustrations/`.

Each slot's `placeholder` caption describes the photo it needs. Use real
photos taken inside the shop, exported as WebP at about 1600px on the long
edge. The whole page should stay under 1.5 MB.
